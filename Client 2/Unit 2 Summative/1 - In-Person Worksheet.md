## 1. End behavior in limit form
**1E.** $f(x) = 2x^7 - 5x^4 + x$. Write the end behavior using limits:
$\displaystyle\lim_{x\to\infty} f(x) = \ ?$ and $\displaystyle\lim_{x\to-\infty} f(x) = \ ?$

**1H.** $g(x) = (1 - 2x)^3(x + 5)^2$

- (a) What are the degree and leading coefficient? *(Don't multiply it all out.)*
- (b) Write the end behavior using limits.
- (c) A different polynomial falls on both ends. What do you know about its degree and leading coefficient?

## 2. Polynomial factoring
**2E.** Factor completely by grouping: $2x^3 + 3x^2 - 8x - 12$

**2H.**

- (a) Factor completely over the reals: $x^4 + 7x^2 - 18$ *(Hint: treat it like a quadratic in $x^2$.)*
- (b) $x = -3$ is a zero of $p(x) = 3x^3 + 7x^2 - 7x - 3$. Use synthetic division to factor $p$ completely.

## 3. Roots of polynomials (including imaginary)
**3E.** Solve $x^2 + 6x + 25 = 0$.

**3H.** A polynomial with real coefficients has zeros $x = -2$ and $x = 1 + 3i$.

- (a) What other zero must it have, and why?
- (b) Write the polynomial of least degree with these zeros and leading coefficient 1, in standard form.
- (c) How many $x$-intercepts does its graph have?
- (d) List **all** zeros of $x^4 + 7x^2 - 18$ from 2H(a).

## 4. Multiplicity
**4E.** $f(x) = -(x - 3)^2(x + 1)(x + 4)^3$

- (a) List each zero with its multiplicity. Does the graph cross or bounce at each one?

**4H.** Write the polynomial of least degree whose graph **crosses** at $x = -3$, **bounces** at $x = 1$, and has $y$-intercept $(0, 6)$.

- (a) Find it in factored form. (b) End behavior in limit form. (c) Sketch it.

## 7. Rational functions: end behavior
**7E.** Find each limit.

- (a) $\displaystyle\lim_{x\to\infty} \frac{5x^3 - 2}{2x^3 + x}$ (b) $\displaystyle\lim_{x\to-\infty} \frac{x^2 + 3}{x^4 - 1}$ (c) $\displaystyle\lim_{x\to-\infty} \frac{2x^3}{x^2 + 1}$

**7H.** $r(x) = \dfrac{2x^2 - 3x + 1}{x + 1}$

- (a) Divide to find the slant asymptote.
- (b) Write the end behavior in limit form.
- (c) Find $\displaystyle\lim_{x\to -1^+} r(x)$ and $\displaystyle\lim_{x\to -1^-} r(x)$.

## Answer key

**1E.** Degree 7 (odd), leading coefficient $2$ (positive): $\lim_{x\to\infty} f(x) = \infty$, $\lim_{x\to-\infty} f(x) = -\infty$.

**1H.** (a) Multiply the leading terms only: $(-2x)^3(x)^2 = -8x^5$. Degree 5, leading coefficient $-8$. (b) Odd degree, negative: $\lim_{x\to\infty} g(x) = -\infty$ and $\lim_{x\to-\infty} g(x) = \infty$. (c) Both ends go the same way, so the degree is **even**; they fall, so the leading coefficient is **negative**.

**2E.** $x^2(2x + 3) - 4(2x + 3) = (2x + 3)(x^2 - 4) = (2x + 3)(x - 2)(x + 2)$.

**2H.** (a) Let $u = x^2$: $u^2 + 7u - 18 = (u + 9)(u - 2)$, so $(x^2 + 9)(x^2 - 2) = (x^2 + 9)(x - \sqrt2)(x + \sqrt2)$. $x^2 + 9$ doesn't factor over the reals. (b) Synthetic division by $-3$ on $3, 7, -7, -3$ gives $3, -2, -1$ with remainder 0. So $p(x) = (x + 3)(3x^2 - 2x - 1) = (x + 3)(3x + 1)(x - 1)$.

**3E.** $x = \dfrac{-6 \pm \sqrt{36 - 100}}{2} = \dfrac{-6 \pm 8i}{2} = -3 \pm 4i$.

**3H.** (a) $1 - 3i$. Complex zeros of real polynomials come in conjugate pairs. (b) $(x + 2)(x - (1 + 3i))(x - (1 - 3i)) = (x + 2)(x^2 - 2x + 10) = x^3 + 6x + 20$. (c) **One** ($x = -2$); the imaginary zeros don't touch the $x$-axis. (d) $x = \sqrt2, -\sqrt2, 3i, -3i$.

**4E.** (a) $x = 3$, multiplicity 2: bounce. $x = -1$, multiplicity 1: crosses. $x = -4$, multiplicity 3: crosses, flattening out (S-shape). (b) Degree $2 + 1 + 3 = 6$, leading coefficient $-1$: $\lim_{x\to\pm\infty} f(x) = -\infty$.

**4H.** (a) Cross means odd multiplicity and bounce means even, so $f(x) = a(x + 3)(x - 1)^2$. Then $f(0) = a(3)(1) = 6$, so $a = 2$: $f(x) = 2(x + 3)(x - 1)^2$. (b) Degree 3, positive: $\lim_{x\to\infty} f(x) = \infty$, $\lim_{x\to-\infty} f(x) = -\infty$. (c) Comes up from the bottom left, crosses up through $x = -3$, passes through $(0, 6)$, comes down to touch the axis at $x = 1$, and turns back up.

**5E.** VA $x = 1$. Domain $x \ne 1$. HA $y = 2$ (same degree: $2/1$). Range $y \ne 2$. $x$-int $(-2, 0)$. $y$-int $(0, -4)$.

**5H.** $r(x) = \dfrac{3(x - 2)(x + 1)}{(x - 2)(x + 2)} = \dfrac{3(x + 1)}{x + 2}$ for $x \ne 2$.
Hole at $x = 2$: plug into the simplified form, $\dfrac{3(3)}{4} = \dfrac94$, so the hole is $(2, \tfrac94)$. VA $x = -2$. Domain $x \ne 2, -2$. HA $y = 3$ (same degree: $3/1$). Range $y \ne 3$ and $y \ne \tfrac94$ (the hole). $x$-int $(-1, 0)$; $x = 2$ is not one because it's the hole. $y$-int $(0, \tfrac32)$.

**6E.** VA $x = -1$. HA $y = 1$. $x$-int $(-3, 0)$. $y$-int $(0, 3)$. Two branches: upper-right (coming down from $\infty$ as $x\to-1^+$, through $(0, 3)$, leveling to $y = 1$) and lower-left (through $(-3, 0)$, heading down to $-\infty$ as $x\to-1^-$, and rising toward $y = 1$ from below as $x\to-\infty$).

**6H.** (a) VA $x = -1$ and $x = 1$. HA $y = 0$ (bottom degree is bigger). $x$-int $(2, 0)$. $y$-int $(0, 2)$.
(b) Test points: $(-\infty, -1)$ negative; $(-1, 1)$ positive; $(1, 2)$ negative; $(2, \infty)$ positive.
(c) $\lim_{x\to-1^-} r = -\infty$, $\lim_{x\to-1^+} r = \infty$, $\lim_{x\to1^-} r = \infty$, $\lim_{x\to1^+} r = -\infty$.
(d) Yes: it crosses $y = 0$ at $x = 2$ and approaches 0 from above as $x\to\infty$. A horizontal asymptote only describes the ends, so the graph can cross it in the middle.

**7E.** (a) Same degree: ratio of leading coefficients, $\tfrac52$. (b) Bottom degree bigger: $0$. (c) Top degree bigger by one, and as $x\to-\infty$ the fraction behaves like $2x$: $-\infty$.

**7H.** (a) $2x^2 - 3x + 1 = (x + 1)(2x - 5) + 6$, so $r(x) = 2x - 5 + \dfrac{6}{x + 1}$. Slant asymptote $y = 2x - 5$. (b) $\lim_{x\to\infty} r(x) = \infty$ and $\lim_{x\to-\infty} r(x) = -\infty$. (c) The numerator at $x = -1$ is $6$ (positive). From the right the denominator is a small positive number, so $\to \infty$. From the left it is a small negative number, so $\to -\infty$.
