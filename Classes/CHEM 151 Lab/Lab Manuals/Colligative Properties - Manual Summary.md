# Colligative Properties
> **What you do:** Record cooling curves for pure water, sucrose solution and NaCl solution in an ice-salt bath and read each freezing point off the curve.
> **Goal:** Find the van't Hoff factor i for each solute and show that the number of dissolved particles, not their identity, sets the freezing point.
> **Key idea:** ΔT_fp = K_fp · m · i
