## Answer key
*From the instructor's handwritten key. I re-checked every number. Where the key's method is unclear, my note explains it. Full worked versions are in [[Exam 2 Review - Equilibrium]].*

**1.** **(a)** forward favored. K is large. (b) would need K small, and (c) needs K intermediate (10⁻² to 10²). (d) and (e) depend on whether the reaction is exothermic or endothermic.

**2.** **(a) and (d).**
- (b) is false: $K_{rev} = 1/K_{fwd}$.
- (c) is false: equal concentrations would mean K = 1.

**3.** **(d)** essentially 0. $Q = [\text{products}]/[\text{reactants}]$, and products are essentially zero.

**4.**
$$K_c = \frac{[\mathrm{CH_2Cl_2}]^2[\mathrm{H_2}]}{[\mathrm{CH_3Cl}]^2[\mathrm{Cl_2}]}$$

**5.** $[\mathrm{NOCl}]_0 = 2.00\text{ mol}/2.00\text{ L} = 1.00$ M.

| R | 2 NOCl | 2 NO | Cl₂ |
|---|---|---|---|
| I | 1.00 | 0 | 0 |
| C | −2x | +2x | +x |
| E | 0.67 | 0.33 | 0.165 |

Here $2x = 0.33$, so $x = 0.165$.

$$K_c = \frac{(0.33)^2(0.165)}{(0.67)^2} = \boxed{4\times10^{-2}}$$

- **(a)** Slightly reactant favored, or "neither." Both are accepted.
- **(b)** Flip the reaction and divide it by 2: $K = (1/0.04)^{1/2} = \boxed{5.0}$.

**6.** $[\mathrm{H_2S}]_0 = 0.0375/1.5 = 0.0250$ M. K is small, so small x is appropriate.
$$1.67\times10^{-7} = \frac{(2x)^2(x)}{(0.0250)^2} \;\Rightarrow\; x = 2.966\times10^{-4}$$
$$[\mathrm{H_2}] = \boxed{5.93\times10^{-4}\ \mathrm{M}} \quad [\mathrm{S_2}] = \boxed{2.97\times10^{-4}\ \mathrm{M}} \quad [\mathrm{H_2S}] = 0.0244\ \mathrm{M}$$

**7.** Small x is appropriate:
$$\frac{(2x)^2}{(1.2)(0.80)} = 1.0\times10^{-5} \;\Rightarrow\; x = 0.001549$$
$$[\mathrm{N_2}] = \boxed{1.198\ \mathrm{M}} \quad [\mathrm{O_2}] = \boxed{0.7985\ \mathrm{M}} \quad [\mathrm{NO}] = \boxed{0.00310\ \mathrm{M}}$$

**8.** Keep reaction 1 as is. Flip reaction 2 and multiply it by 2.
$$K_p = K_{p1}\left(\frac{1}{K_{p2}}\right)^2 = (3.21)\left(\frac{1}{1.495}\right)^2 = \boxed{1.436}$$

**9.** The forward reaction becomes favorable until equilibrium is re-established.

**10.** The reverse reaction becomes favorable until equilibrium is re-established.

**11.** *(The key just says "Do you even know?")* When a system at equilibrium is disturbed (by concentration, pressure/volume, or temperature), it shifts in the direction that reduces the disturbance.

**12.** Q tells us where the reaction is in a non-equilibrium state. We calculate Q to see which way the reaction will go to re-establish equilibrium:
- Q < K → forward
- Q > K → reverse

It's the mathematical version of the qualitative Le Chatelier's principle.

**13.**
$$K_w = [\mathrm{H_3O^+}][\mathrm{OH^-}] = (1\times10^{-7})(1\times10^{-7}) = \boxed{1\times10^{-14}}$$

**14.**
- **(a)** Flip and multiply by 2: $K = (1/0.143)^2 = \boxed{48.9}$.
- **(b)** $Q_c = 0.0200/0.0400 = \boxed{0.5}$.
- **(c)** Q > K, so it goes in **reverse**. (For the reverse reaction, $K = 1/0.143 = 6.99$.)
- **(d)** Solve $6.99 = \dfrac{0.04 + x}{0.02 - x}$ to get $x = 0.0125$.
  - $[\mathrm{C_6H_{12}}] = \boxed{0.0525\ \mathrm{M}}$
  - $[\mathrm{MCP}] = \boxed{0.0075\ \mathrm{M}}$
- **(e)** The key writes Q for the reverse reaction: $(0.0525 + 0.020)/0.0075 = 9.66 > 6.99$, so the reverse of the reverse, which is **forward**.
  *Written for the reaction as given:* $Q = 0.0075/0.0725 = \boxed{0.103} < 0.143$, so it shifts **forward** (toward MCP). Same answer.
- **(f)** Solve $0.143 = \dfrac{0.0075 + x}{0.0725 - x}$ to get $x = 0.00251$.
  - $[\mathrm{MCP}] = \boxed{0.0100\ \mathrm{M}}$
  - $[\mathrm{C_6H_{12}}] = \boxed{0.0700\ \mathrm{M}}$
